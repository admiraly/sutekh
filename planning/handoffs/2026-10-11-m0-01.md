# M0-01 handoff: native build and platform skeleton

Status: implemented and locally verified on Linux (GCC 13.3.0, CMake 3.28.3, Ninja 1.11.1). Not independently reviewed. Not pushed.

## Modified paths
- `CMakeLists.txt` (new): C17 project `sutekh` 0.1.0; targets `su_platform` (static) and `sutekh` (executable).
- `cmake/SutekhWarnings.cmake` (new): `-Wall -Wextra -Werror -pedantic` for GNU/Clang; `/W4 /WX` for MSVC.
- `src/platform/su_platform.h`, `src/platform/su_platform.c` (new): `su_platform_monotonic_ns()` (clock_gettime CLOCK_MONOTONIC, or QueryPerformanceCounter behind `_WIN32`) and `su_platform_pid()`.
- `src/platform/sutekh_main.c` (new): `--version`, `serve`, `worker`. Placed under `src/platform/` because that is the only source directory in my write scope; move it when `src/` gets a proper entry point.
- `tools/dev.py` (new): stdlib-only `configure`, `build`, `clean`. Argument lists, `shell=False`, profile allowlist (`dev`=Debug, `release`=Release), prints commands and tool versions. `clean` removes only `<repo>/build`.
- `planning/handoffs/2026-10-11-m0-01.md` (this file).
- `third_party/`: not created. Git does not track empty directories, and nothing is vendored.

Frozen headers in `include/sutekh/` were read but not modified. `--version` reads `SU_ABI_VERSION`, `SU_IR_VERSION_STRING` and `SU_ARTIFACT_FORMAT_VERSION` from them.

## Commands and results
1. `python3 tools/dev.py clean` -> "nothing to clean", rc 0.
2. `python3 tools/dev.py build --profile dev` (first run failed: `clock_gettime` implicit declaration, because `_POSIX_C_SOURCE` was defined after `stdint.h`. Fixed by moving the macro to the top of `su_platform.c`.)
3. Re-run after `clean`: configure with `-G Ninja -DCMAKE_BUILD_TYPE=Debug`, 4 steps built and linked, rc 0.
4. `./build/sutekh --version` -> rc 0. Output: `sutekh 0.1.0`, `abi_version 1`, `ir_version 0.1`, `artifact_format 1`, `build_type Debug`, `compiler GNU 13.3.0`, `pid <n>`.
5. `./build/sutekh serve` -> rc 1. Stdout: `{"ok":false,"error":{"code":"SU_E_UNSUPPORTED_METHOD","status":12,"message":"role 'serve' is not implemented in the M0 skeleton"}}`. Parsed with `json.load` successfully.
6. `./build/sutekh worker` -> rc 1, same JSON shape.
7. `./build/sutekh bogus` -> rc 2, usage on stderr.

## Unrun checks
- `build --profile release`.
- Clang build, and the `-Werror` policy under Clang.
- Make generator (only Ninja was exercised; `dev.py` falls back to the CMake default generator when Ninja is absent, which is untested).
- Windows / MSVC / clang-cl build and the QueryPerformanceCounter path (`#ifdef _WIN32`).
- `su_platform_monotonic_ns()` has no test or caller yet. It was compiled but never executed.
- Sanitizer lanes.
- `dev.py` error paths (missing cmake, unknown profile).

## Blockers and notes
- No blockers for the Linux dev path.
- `serve`/`worker` return `SU_E_UNSUPPORTED_METHOD` as the M0 contract requires. This is not a success.
- Output is plain text for `--version` and single-line JSON for the errors. The JSON shape is not yet checked against `docs/AGENT_RPC.md` beyond the `ok:false` / `error` object.
