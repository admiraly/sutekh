## W^X FINDING

**The JIT mapping is rwx on Linux, with both g++ and clang++ builds.** `/proc/self/maps` shows the mapping holding the generated function as `rwxp` (anonymous, 128 KiB). The JIT runtime therefore does not give W^X here by default. This is reported as a finding for M1-01 to resolve (for example, a dual mapping or `MAP_JIT` path, or an explicit `mprotect` flip). Not fixed in M1-00, since the bootstrap only reports it.

## Broker

- `tools/broker/broker.py`: SQLite (WAL, synchronous=FULL) in `build/broker/` by default (covered by the `/build/` ignore). Job key = sha256 over canonical JSON of `(system_id, inputs, argv, env, cwd)`. States queued, running, succeeded, failed, cancelled, stale.
- Dedupe returns the existing job, and a failed, cancelled or stale job is re-run only with `--resubmit`. Supersession cancels queued and running older jobs of the same `system_id`; running children are killed by the runner.
- `validate_result` compares the bound identity (`semantic_hash`, `layout_generation`, `backend`) and marks a succeeded job stale on a mismatch (the stale state is durable).
- Runner: flock on `runner.lock`. On start it kills the process groups of jobs left running and marks them failed. Children get `RLIMIT_AS`, a new session, a timeout, and a log file (sha256 recorded). Env allowlist and cwd restricted to the repo or the state dir. argv executed with `shell=False`.
- CLI: `submit|status|cancel|list|run-once|gc`, JSON output, exit codes 0/1/2/3.

## Unrun or limits

- Not run: the `planning/tasks.json` update, CMake or native targets (no native code changed), and any Windows path.
- Monotonic timestamps are only comparable within one boot.
- Recovery kills a recorded child process group only if the pid is still a group leader (pid reuse is not fully excluded).
- The memory cap uses `RLIMIT_AS`, which counts virtual memory, so it is strict for JIT or large-mapping workloads.
- Not implemented: artifact directories, a result payload (the broker records only exit code and log hash), and `gc` is not tested.
