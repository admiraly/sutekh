# Issue 121: quantum-local spatial controls

## Implemented

Cache the spatial stage for matching emitter/gain/pitch leaves within one
128-frame quantum. Full generational handles and exact float bits are keys;
direct-map collisions recompute. Per-instance/bus parameters, control updates,
audibility, ranking, cursor advancement, fades and filtering keep their original
cadence and arithmetic. Nothing is cached across quanta or serialized. The
256-entry cache uses 18,432 bytes of stack scratch on x64; persistent runtime
bytes and render allocations are unchanged. Public interfaces are unchanged.

An independently compiled uncached event object is the executable reference.
The differential test compares 14,168,168 recorded PCM/checkpoint bytes exactly
under both Clang and MSVC. Both produce SHA-256
`4475447c001efa06372e176fc0eb7de3052c9d38a8c4947af3aa6cf53fcf0fe2`.
Coverage includes mixed gain/pitch, shared emitters, direct-map collisions,
moving listeners/emitters, Doppler, low-pass, all virtual modes with saturated
and unsaturated physical pools, per-instance parameters, steals and restoration
at partial-quantum positions.

## Measurements

Windows 11 Pro 10.0.26200 x64, Intel Core i5-12400F, Clang 23.1.3 Release,
C17 strict warnings. Baseline revision: `7aa23242a98fc29ebcd364b3a806129c69f7d1c1`.
Three alternating uncached-reference/cached runs, 60 seconds rendered per
variant per sample, default 512 logical / 64 physical voices, 256 moving
emitters. Units are the benchmark's CPU-labelled milliseconds per second of
rendered audio. Source and artifact hashes, every sample, ranges and metadata
are in `planning/evidence/issue-121/summary.json` and the raw JSON files.

| Variant | Uncached median (range) | Cached median (range) | Median reduction |
| --- | --- | --- | --- |
| full | 129.267 (113.267-131.600) | 102.217 (98.400-130.967) | 20.9% |
| no_clustering | 111.483 (108.350-135.883) | 91.483 (89.800-130.933) | 17.9% |
| voices_only | 83.617 (73.750-94.167) | 72.617 (60.533-77.567) | 13.2% |

This shared host was not isolated; the substantial variation and overlapping
ranges are not a fine-grained performance gate. Hardware counters were not
collected. Original pre-edit 20-second baseline samples and one exploratory
cached run are retained separately, not mixed into the paired statistics.
