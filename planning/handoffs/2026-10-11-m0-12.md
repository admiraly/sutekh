## What changed, by audit item
1. **T13 targets.** `TIMING_TARGETS` mirrors the five rows of docs/PERFORMANCE.md section 2. `compare_target` gives `met` / `not_met` / `not_comparable` per target, with the gate that failed named. Gate facts come from the fixtures (source bytes, schema equality, row count, case count). The reusable-worker evaluate distribution is new and is what the preview target uses. Verdicts sit in `report["timing_targets"]` and are labelled provisional (C10). T13 passes once measurements exist and a verdict is recorded for each target.
2. **T11.** Default 1,000 iterations (`--reload-iterations` kept). Five-kind cycle: `install`, `revert` (install v2, re-install v1), `fail_stale_revision`, `fail_past_tick` (`allowed_effective_tick` one behind, mapped to `SU_E_STALE_REVISION` by reload.c:199), `fail_layout_generation` (a correct candidate with layout_generation 2, refused with `SU_E_SCHEMA_MISMATCH`). State is checked after each kind. RSS compares medians of a warm-up window [200,300) and the final tenth [900,1000) against the same 8192 KiB bound. Under ASan the engine gets `quarantine_size_mb=1` (documented in the test).
3. **T04.** Added cases: oversize IR (262145 bytes, RESOURCE_LIMIT), capsule and IR depth 40 (RESOURCE_LIMIT), malformed JSON and invalid UTF-8 (PARSE), duplicate key in an instruction (DUPLICATE_KEY), capsule profile unsupported (TYPE), system_id, query, duplicate field id and duplicate field name (SCHEMA_MISMATCH), unknown-field load (UNDECLARED_READ), missing store (MISSING_STORE), and an oversize 1 MiB + 1 `capsule.submit` line (RESOURCE_LIMIT). Each is exact-code and no-state-change checked. A coverage guard fails T04 if a required code or stage 1-7 is missing.
4. **T12.** Primary evidence is the strace probe run on the binary under test. `pass` requires both controls detected, zero build-tool execs, demo passed. `fail` is a failed test. `inconclusive` is `not_run` with the reason. PATH-shim and `/proc` polling remain as secondary checks only.
5. **Runner hygiene.** A body with zero recorded checks is `not_run`. Counts are written per test (`checks_total`, `checks_failed`, `checks_recorded`, `checks_dropped`); the old silent 300 cap is now 20,000 and counted. T08's optional checks are required (`restored_from`, reply revision and tick, self-consistency). OS facts (`/proc/<pid>/stat`: parent, start time, state) replace trust in engine pids in T05, T10 and T12. T10 captures victim identities in the killer thread before SIGKILL. T00 runs a clean Debug configure and build in a `mkdtemp` directory outside the repo and checks that the binary under test reports the same version fields as the clean build (pid excluded). T09 docstring corrected.
6. **Self-tests.** 138 checks (was 82): comparator cases including boundary and proxy, stage table, manifest cross-checks, zero-check guard, counting and cap, `/proc` parsing and identity, sanitizer detection, quarantine env, RSS window, oversize variant, version identity, T11 cycle, and the probe's absolute-path detection.
