## Mechanism as built

- Descriptor: `system_id`, `schema_id` "rts", `operator_version` 1, `constants_hash` (literal, checked by `rts_native_ops`), field table ascending (`rts.spatial`: reads 1,2,3,4,5,7,15,16; writes 21 to 30; `rts.scatter`: reads 1,36,37,38; read_write 39), `run`, `host_ctx` (the static context).
- Views: as M3-04a `run_host`. Write-only fields of `rts.spatial` are stored for every row by the operator (no working copy exists for write-only fields, deviation 4 of the M3-04a handoff). `rts.scatter` field 39 is read_write, so `run_host` seeds staging with the working value and the operator adds to staging.
- Alive and generation come from `su_world_alive_view` and `su_world_generation_view` on the const world.
- Gather: valid iff `formation_slot != NONE && slot < cap && alive && generation == formation_gen`. Anchor position read from the tick-start pos column.
- Grid: counting sort over alive units with `hp > 0`, 512 x 512 cells of 64 units, ascending slot within a cell. Scratch is static (see deviation 2).
- Query: `R = isqrt(range_sq)`, `rc = (R + 63) >> 6` (SU_E_INTERNAL above 8, and above `range_sq` 262144), rings 0..rc, rows ascending then columns ascending, clipped to the grid. Budget K = 128 examined entries (self and same-team count when examined). Best by `(dist_sq, slot)`. `truncated = box_total > 128` where `box_total` counts every indexed entry in the ring box (the budget does not stop the count).
- Non-query rows (including dead rows, literal 4.1(c) "others") write `target_slot = NONE`; `su_world_zero_dead` then zeroes dead rows after the commit.
- Scatter: alive shooters in ascending slot order with `dmg_target != NONE` and `dmg_out != 0`; target valid iff `t < cap && alive && generation == dmg_target_gen && kind == 1`; `incoming = min(a + b, 0xFFFFFFFF)`.
- Failure: a fault seam or a domain violation returns `SU_E_INTERNAL` (or `SU_E_RESOURCE_LIMIT` above 1,000,000 rows); `run_host` returns before commit, so the tick aborts with the committed root unchanged.

## Deviations and findings (recorded)

1. **B1** (above). The M3-04 descriptors use the hashes of the M3-04 texts. Equality with the committed records is not achieved.
2. **Static scratch, not admitted host_ctx.** The registry descriptors are static, so the capacity is not known when they are built. The operators use static scratch sized by `RTS_OPS_MAX_ROWS` = 1,000,000 (about 8 MiB of BSS, touched only when a host entry runs). `host_ctx` carries the fault and instrumentation state. Capacity above 1,000,000 is `SU_E_RESOURCE_LIMIT`. The operators are not reentrant across worlds in one process; the scheduler runs them serially and each worker process runs one world.
3. **Store-set instrumentation** is a runtime hook (`RtsOpsCtx.instr`), compiled into every build and attached only by tests, not a separate debug build (4.4 says debug). It checks that every declared write is stored for every row of write-only fields, that the scatter stores only target rows, and that no store names an undeclared write. Undeclared columns unchanged across a tick are covered by the M3-04a `run_host` tests, not re-tested here.
4. **Dead rows, literal 4.1(c) and the model.** Read literally, 4.1(c) writes `target_slot = NONE` into dead rows too. The model does the same. The engine then zeroes dead rows after the commit (`su_world_zero_dead`), so the committed value is 0. The differential compares dead rows as zero on both sides. Contract wording could say "alive rows" to avoid this reading.
5. **M3-M24 is not equivalent.** Section 15 calls the gather alive check equivalent because despawn bumps the generation. But `set_fields` accepts any nonzero `formation_gen`, so a member can carry the generation a dead anchor holds (e.g. 2 after one despawn). Without the alive check that member is valid and reads the zeroed anchor position. A test covers this case (`gather: forged generation`) and the mutant is killed. Owner decision: keep the alive check and correct section 15 M3-M24 (or constrain `formation_gen` in 2.2).
6. **M3-M06 is equivalent for the committed state.** A scatter write to a dead row is erased by `su_world_zero_dead` before the commit is read. The alive check is kept as defence; the defensive test (`dead slot receives nothing`, which sets a dead slot's kind through `su_world_init_committed`) passes with and without the check, so the mutant is recorded as equivalent, not detected.
7. **M3-M09b** is equivalent (saturating add, 4.3). Recorded.
8. **Fault seams** (N9) return `SU_E_INTERNAL` at a chosen point; the test shows the tick aborts with the committed root unchanged and that a rerun on the same world succeeds. This is not checkpoint recovery in a replacement worker (T-RTS-REPLAY-3 is M3-05).
9. **Model read.** The task allowed reading the Python model's known answers and tests as expected values. I also read `bench/rts/ref/model.py` (`spatial_phase`, `_target_query`, `scatter_phase`) before writing the operators. Implementation followed the contract text and the known answers were written from the contract. The differential is therefore not fully independent of that reading. The M3-02 rule "model author does not read M3-04 sources" was not affected: I did not write the model.
10. **Fault seam and instrumentation code is always compiled** (disarmed by default). This is a product-visible test seam, as N9 requires seams to exist.
