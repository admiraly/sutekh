## Behaviour
- Registry: txid per candidate or creation system; states RECEIVED to INSTALLED, RETIRED, REJECTED, STALE, CANCELLED. 128 records. INSTALLED never evicted; terminal records evicted oldest-first. Evicted txids resolve to nothing.
- Install (`candidate.install {candidate_id, world_id, expected_world_revision, allowed_effective_tick}`): stale revision (STALE) -> load and verify with recorded hashes (REJECTED) -> system must be in the schedule -> layout check (field ID/name/type, access within world, query, schema_version, generation: SU_E_SCHEMA_MISMATCH) -> prepare VM context -> evidence gate (supervisor's evaluation must be `passed`, else SU_E_CANDIDATE_FAILED) -> admission recheck -> boundary (world tick must equal `allowed_effective_tick`, else STALE) -> publish (entry swapped, old revision RETIRED, old module and context freed). World state, worker PID and other systems untouched; world revision +1.
- Rejections return ok:false with `txid=N state=S: reason` in the message. Schedule is unchanged on any failure.
- Multi-system tick: systems run in order; each system's staging is committed to working before the next runs; any failure aborts the open tick.

## Deviations and rulings for the contract owner
- Install requires a passing evaluation (AGENT_RPC section 2). The supervisor records the evaluation; the client cannot set it.
- `allowed_effective_tick` must equal the current tick (STALE otherwise). There is no deferred pending install.
- Install replaces the entry with the same `system_id`. Adding a system to a live world is not supported.
- A code-only install cannot add a writable field or change layout generation (SU_E_SCHEMA_MISMATCH).
- Prepare and publish run in the same worker request, so the admission recheck is a guard for a future asynchronous prepare.
- Expected columns in a candidate test file may name only fields the candidate binds (the evaluation world is built from its own field table).
- `world.create` with multiple systems registers each initial system as revision 1 in the registry.
