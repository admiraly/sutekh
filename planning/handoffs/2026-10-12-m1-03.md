## Design (what the code does)
- Caps: AVX2 reported only if CPUID.1:ECX OSXSAVE[27] and AVX[28], XGETBV(0) bits 1 and 2, and CPUID.7:EBX AVX2[5]. Other architectures: scalar only. MSVC detection not implemented.
- Frame: SU-LIR register r is a 32-byte slot at `[rsp+32r]`; frame base 32-byte aligned (`and rsp,-32`); frame = round32(32R + 8(in+out)); above 65536 bytes the lowering returns `SU_NLOW_RESOURCE` (-> `SU_E_RESOURCE_LIMIT`). Callers then compile SCALAR (`su_native_best_backend` documents this).
- Vector body: all loads and stores are `vmovdqu`. LT is unsigned: xor both operands with 0x80000000, then `vpcmpgtd`. SELECT: `vpblendvb(false, true, mask)`. Bools are all-ones lane masks in the vector body and 0/1 in the scalar epilogue; a register is always defined before use within a row, so the two representations never meet.
- Callee-saved: rbp (frame base), rbx, r12, r13, r14 pushed and restored. Zero rows return after vzeroupper with nothing pushed. vzeroupper before every ret.
- Source map: one range per SU-LIR instruction, recording the vector body. The scalar epilogue body is in the artifact but not in the map (documented in the source comment).
- Artifact hash differs from scalar (backend id and caps are hashed).
