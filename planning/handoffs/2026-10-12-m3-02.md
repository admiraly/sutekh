## Contract ambiguities and findings (question, choice made)

- **Q1 Generation at spawn.** 4.1 says initial generations are 1 and despawn bumps the generation. Choice: slot generation starts at 1, despawn increments it, spawn does not change it (a re-spawned slot carries the post-despawn generation). Owner should confirm.
- **Q2 M3-M24 is not equivalent (finding).** The contract says gather without the alive check is equivalent because despawn bumps the generation. But 2.2 checks no liveness of `formation_slot`, and `spawn` can name a dead slot at its current generation. Choice: the check `check_gather_known_answers` builds exactly this case through `spawn` alone, and the mutant is recorded as detected. Owner: either add a liveness refusal for `formation_slot` in spawn and set_fields, or reclassify M3-M24.
- **Q3 M3-M06 alive gate is not reachable through the full tick (finding).** Dead rows are zeroed at the boundary, so `kind` is 0 and the kind check refuses them. Choice: the alive gate is tested at operator level with a white-box row that still has `kind = 1` after death. The mutant is detected there. In the full tick it is equivalent under the zeroing invariant. The owner should decide whether the operator contract needs the alive gate.
- **Q4 Denominators for missed and valid_but_not_nearest (4.2).** Not stated. Choice: primary denominator is queriers with an oracle-qualifying enemy. Also reported: rate over all queriers and rate over valid targets only.
- **Q5 Ratio when the oracle distance is 0.** Choice: 0 vs 0 gives 1.0; nonzero vs 0 gives infinity and is counted in p95, which would fail the gate.
- **Q6 Querier sampling.** Not specified. Choice: splitmix64_v1 seed 20261012, partial Fisher-Yates over armed units in slot order; if fewer than 1,024 armed units exist, all are used (the 1,024-row probe used 964). M3-01/M3-06 must fix this for the committed scene.
- **Q7 Event record fields for the events digest.** Not specified. Choice: canonical JSON `{"gen","kind","seq","slot"}` per retained event. Ring eviction is applied, and `dropped` is in the state digest.
- **Q8 Engine digest compatibility (open).** 9.2 refers to the M2 recovery digest. The M2-00 canonical encoding is not in this contract, so my state digest is model-defined (`rts-model-state/0.1`). It is not byte-compatible with the engine and this is unrun. "Retired" is defined as the despawn count.
- **Q9 Anchor speed and orders in the probe.** 7.3 gives no anchor speed. The probe uses 96. Team split and weapon choice are also probe choices. This affects only the probe, not the committed scene.
- **Q10 Formation to a non-anchor row.** 2.2 does not require `formation_slot` to name a kind-2 row, so a member can follow a live unit at the same generation. Not a bug in the model; owner should decide whether it is intended.
- **Q11 Random row distribution for the IR differential.** Not specified. Choice: uniform domain values with edge bias, seed 20261012, 1,500 rows per system.
