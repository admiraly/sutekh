# Numeric profile, IR 0.3 and 3D queries — owner-authorized downstream amendment

Authorization, 18 October 2026: the owner authorized work driven by a downstream 6DOF racing workload outside the milestone order, while M3 (RTS microcosm) remains in progress. This amendment records the scope; it does not close, reorder or waive any M3 gate.

## Scope

1. Numeric profile `fixed_q32_v1`: signed `i32`, `i64` and Q32.32 fixed point with exact rounding, saturation and conversions; deterministic `sqrt` and `rsqrt`. Normative text and decision record: `docs/NUMERIC_FIXED_Q32.md`.
2. IR 0.3 (`LIVE_IR_SPEC.md`, section "IR 0.3"): typed fields over u32 storage lanes, typed registers including `v3` and `quat`, the profile's opcodes, verifier rules, reference VM, semantic hash format 3. The native backend refuses 0.3 modules (no lowering, no fallback inside the backend; the VM tier runs them).
3. A 3D spatial capability (`docs/SPACE3D.md`): deterministic broadphase and narrow-phase queries (swept sphere against sphere, oriented box and capsule; segment against oriented finite gate plane), exposed as a declared host operator with bounded, ordered per-row results.
4. A synthetic fixture and benchmark scene (`6dof_racer_microcosm`) with replay digests and timing observations at 120 Hz for N = 8, 32, 256. No original assets; all content is generated.

## Constraints kept

- Additive only. IR 0.1 and 0.2 modules keep their semantic hashes and behaviour byte for byte.
- World storage remains u32 SoA. 64-bit fields occupy two consecutive field IDs; canonical state, snapshot formats, migration and the control plane are unchanged by this amendment.
- Platform and control-plane code belong to the Windows host work stream; this stream changes them only where a shared contract requires it, and records each such change in its handoff.
- Evidence rules (C10, C20): timing figures are observations on the named machine, not qualification.
