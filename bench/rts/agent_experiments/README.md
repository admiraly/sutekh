# Agent-authored RTS behavior experiments

These candidates use the real `capsule.submit`, `candidate.evaluate`, and `candidate.install` pipeline. They remain IR 0.1 and do not change canonical `capsules/rts` gameplay. Candidate order is B3 formation catch-up, B2 kiting, then B1 low-HP retreat. Generators reproduce the emitted candidate files; CTest evaluates the locked hidden fixtures and installs each behavior in a scratch full six-system world.

The hidden fixtures were authored by `/root/hidden_behavior_fixtures` without reading implementation, model or author outputs. Their manifest pins inputs and expectations. Binding a test to a capsule basename changes only that reference. The baseline must reject each behavior's fixtures; B2 and B1 must also reject their predecessor. Earlier behavior fixtures pass each successor. A different reviewer, `/root/review_limits_v2`, reviewed source and independently evaluated legal-domain rows; reports are in `planning/evidence/m3-independent-review`.

Interpretation decisions: B3 uses squared Euclidean distance strictly greater than 4096, then doubles speed and caps each axis at its remaining distance; the prior target stop gate remains until B2. B2 reads post-combat cooldown. B1 applies retreat to positive-HP live units, preserving HP-zero anchor behavior, overrides explicit orders, bypasses engagement stop, and gates new fire rather than deleting existing projectiles. Existing projectile arrivals retain their original semantics. Goal/move add ordering before damage for new HP reads. Diagonal threshold and anchor cases were excluded from the blind fixtures because the specification is ambiguous; these interpretations are explicitly reviewed choices, not hidden oracle claims.

Records describe this bounded experiment, not general agent capability or performance qualification. Token/tool-call counts unavailable from the harness remain null. The initial author-only records remain historical and are superseded for acceptance by the independently authored fixture and live-install records.
