Sutekh is pre-implementation: there are no supported runtime releases yet.
Reports about the current `main` branch and repository tooling are welcome.
The project does not claim that its planned runtime or native workers are
safe sandboxes. Development tools and contributions can execute host code.

## Private vulnerability reporting

Use [GitHub private vulnerability reporting](https://github.com/admiraly/sutekh/security/advisories/new)
for vulnerabilities. Include the affected commit, environment, minimal
reproducer, impact, and suggested mitigation if available. Do not send live
credentials, proprietary assets, or unnecessary personal data. Avoid public
issues and PRs that disclose an unpatched exploit.

No security email address, bug bounty, response-time SLA, or guaranteed support
term is currently published. The maintainer will assess reports and coordinate
disclosure and remediation where possible. If the private-report form is
unavailable, request a private reporting channel from
[the owner](https://github.com/admiraly) without publishing exploit details.

For non-sensitive defects, use ordinary GitHub issues. Commercial license
discussions do not themselves establish security support commitments.
